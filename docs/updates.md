# Updates

DeckHost checks for a new release now and then (turn it off in **DeckHost settings**). When one is out, a notice appears at the top: **What's new** shows the release notes, and the install button downloads the package for your system, checks it against the release's checksums, closes DeckHost, installs it and starts the new version. Your profiles and settings stay.

- **Skip this version** stops the notice for that release.
- **Include pre-releases** (DeckHost settings) offers alpha, beta and release-candidate builds too; they are offered anyway when you already run one.
- The update is never installed without you choosing it.
