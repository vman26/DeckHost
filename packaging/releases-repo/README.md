# DeckHost releases

Downloads, documentation and problem reports for DeckHost, the host for MiraBox StreamDock N4 Pro, Elgato Stream Deck and a browser Web Deck.

- **Download:** [the latest release](../../releases/latest) (Windows setup, macOS zip, Linux tar.gz; `SHA256SUMS.txt` to check a download).
- **Documentation:** https://vman26.github.io/DeckHost-releases/
- **Report a problem:** in DeckHost, ☰ → Help and support → Report a problem, or [open an issue](../../issues/new/choose).

DeckHost checks this repository for updates by itself.
