# Code of conduct

DeckHost follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, assume good intent, give and take criticism about code
and ideas, not people. Harassment, insults and personal attacks aren't tolerated, here or in any
DeckHost space (issues, discussions, the plugin catalog).

Report a problem with someone's behavior to the maintainer through a
[private security advisory](https://github.com/vman26/DeckHost/security/advisories/new) (it's
the private channel GitHub offers) or by email to the address on the maintainer's GitHub profile.
Reports are handled confidentially.
